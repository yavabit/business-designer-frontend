## ✨ Возможности

### 🏗️ **Бизнес-схемы**

- 📊 **Визуальное проектирование** - создавайте сложные бизнес-процессы с помощью drag&drop
- 🔄 **Интуитивный интерфейс** - простой и понятный конструктор на основе React Flow
- 🎯 **Детализация процессов** - наглядно отображайте каждый этап бизнес-процесса и редактируйте его под себя

### 🤖 **Агенты**

- ⚡ **Автоматизация workflows** - настраивайте цепочки запросов и email-уведомлений
- 🕒 **Гибкое расписание** - запускайте процессы разово или на регулярной основе
- 📧 **Интеграция с почтой** - автоматическая отправка email по заданным сценариям

### 👥 **Совместная работа**

- 🌐 **Real-time редактирование** - несколько пользователей могут работать одновременно
- 🖱️ **Визуализация курсоров** - видите действия других участников в реальном времени
- 👤 **Online-пользователи** - отслеживайте кто сейчас работает с процессом
